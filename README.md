# Muhammad Fudail Wasif — Developer Portfolio

A modern, responsive personal portfolio showcasing my projects, technical skills, and journey as a frontend developer.

Built with **React, Tailwind CSS, and GSAP**, with a focus on interactive experiences, clean design, and smooth animations.

### Live Demo

**[View My Portfolio](https://fudail-portfolio-mauve.vercel.app/)**

## Tech Stack

| Technology | Purpose |
|---|---|

| GSAP | Animations and interactive effects |

## Getting Started

To run this project locally, follow these steps.

**1. Clone the repository**

```bash
git clone https://github.com/fvyalwayshigh-sys/Fudail-Portfolio.git
```

**2. Navigate to the project directory**

```bash
cd Fudail-Portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal.
